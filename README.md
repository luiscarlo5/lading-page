# GESTUS: tecnologia assistiva através do olhar

Landing page do projeto GESTUS (UFC · PROTECS · Empreende UFC).

## Publicar no GitHub Pages

1. Crie um repositório no GitHub (por exemplo, `gestus`).
2. Envie para a raiz do repositório o arquivo `index.html` e a pasta `assets/`, mantendo a estrutura.
3. No repositório, vá em **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)`, e clique em **Save**.
5. Em alguns minutos o site fica disponível em `https://SEU-USUARIO.github.io/gestus/`.

Se o repositório se chamar `SEU-USUARIO.github.io`, o site fica direto em `https://SEU-USUARIO.github.io/`.

## Estrutura

```
index.html          página completa (HTML, CSS e JS no mesmo arquivo)
assets/img/         imagens otimizadas (WebP) e favicon
```

## Editar

Todo o texto está no `index.html`. Os contatos ficam na seção `id="contato"`.
